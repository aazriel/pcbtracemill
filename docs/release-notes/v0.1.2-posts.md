## Reddit (r/PrintedCircuitBoard, r/hobbycnc, r/CNC, r/diyelectronics)

**Title:** PCB TraceMill 0.1.2: free Gerber-to-G-code for milling PCBs at home. Auto-levelling now shows where every bit finds Z0.

I'm building PCB TraceMill, a free desktop app that turns Gerber and Excellon drill files into G-code for hobby CNC routers (Mach3, GRBL, LinuxCNC). It covers isolation, drilling, hole milling and cutout with tabs, with a 3D simulation before you cut. It runs on Windows, macOS and Linux.

What's new in 0.1.2:

- **Z0 map:** a map of the board shows where each bit touches the copper with the probe. You can move any point by clicking on the map. If the copper there is no longer connected to the probe clip, the app says so and uses a safe point instead.
- **Choose which files to probe:** pick the files that get height correction. The others are saved as they are.
- **Your tools first:** the recipe picks your own tools before the starter kit. The tool library can be exported and imported, and it survives updates.
- **Faster simulation:** about twice the frame rate.
- **Update banner:** the app tells you when a new version is out.

Download (free): https://github.com/aazriel/pcbtracemill/releases/tag/v0.1.2
Website: https://aazriel.github.io/pcbtracemill/

Feedback and bug reports are very welcome, especially from Mach3 and GRBL users who probe their boards.

## CNC forums (CNCZone "PCB Milling", machsupport.com Mach3 forum, openbuilds forum)

**Title:** Free PCB milling software with Mach3 auto-levelling (no macros needed)

Hi all. I've been milling PCBs on a Mach3 router and wrote my own software for it, which is now free for everyone: PCB TraceMill.

What may interest Mach3 users is the auto-levelling. The probe program is plain G-code, and Mach3 keeps the measured heights in its own # variables. The corrected files read them directly, so there are no macros to install and no file to load. Before each bit the file stops, you clip the probe on, and it finds Z0 on copper that is still connected to the clip. A map shows where each bit will touch.

It also covers isolation with automatic depth from the measured copper gaps, drilling, milling big holes, cutout with tabs, double-sided boards and a 3D simulation. GRBL and LinuxCNC are supported too.

https://aazriel.github.io/pcbtracemill/

Feedback from people with real machines is very welcome.
