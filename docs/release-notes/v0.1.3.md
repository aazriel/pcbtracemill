Already on 0.1.1 or 0.1.2? Install 0.1.3 over it. Your settings, saved tools and .tmill projects carry over.

### First start
- **Windows:** the installer is not code-signed yet, so SmartScreen shows *"Windows protected your PC"*: click **More info -> Run anyway**.
- **macOS:** the app is not notarised yet. Right-click the app and choose **Open**. If macOS says it is damaged, run once in Terminal: `xattr -cr "/Applications/PCB TraceMill.app"`
- **Linux AppImage:** `chmod +x PCB-TraceMill-0.1.3-x86_64.AppImage` and run it. On Ubuntu 24.04+ you may need `--no-sandbox`.

## What is new in 0.1.3

### Import in three steps
- **1. Design program:** pick KiCad, Altium, Eagle / Fusion Electronics, EasyEDA or Other. A box below shows **how to export the files from that program**, step by step with the exact menu names, and **what to export**: what you must have (copper), what is strongly recommended (board outline and drill files, named the way that program names them) and what is optional (silkscreen, solder mask).
- **2. Files, folder or ZIP:** three big choices, with the best one for your program marked.
- **3. Choose them** in the app's own file browser. Cancelling it takes you back to step 2.
- Files dropped onto the window only ask for the program. Adding files to a board starts at step 2.

### Board
- **Clearly different layer colours:** red top copper, blue bottom copper, yellow outline, white drill holes, green and magenta solder mask, cyan silkscreen, and so on. No two layers share a colour. The new palette button on the layer list recolours an older project.
- **Compact layer list:** each row shows only drag, show / hide, colour and name. Click the name to fold out the type, side, numbers, re-import and delete.
- A hidden layer is greyed out, so you see at a glance which layers are shown.
- **Next: Manufacture** is now a big, bright green button.

## Highlights
- Isolation (with smart clearance), copper clearing, drilling, hole milling, cutout with tabs
- Realistic 3D material-removal simulation
- Auto-levelling with probing (Mach3 heights kept in variables - no file to load), with a map of where each bit finds Z0
