## PCB TraceMill 0.1.2

### New
- **Board map on the Export page**: shows where each bit finds Z0 with the probe, as numbered dots in the colour of its file. Point at a file (Auto-level step 3 or the files table) to light up its points.
- **Your own Z0 point per bit**: press *Move* next to a bit and click on the map, or type X/Y. *Auto* puts it back. If no copper there is still joined to the probe clip, the automatic point is used and yours is shown crossed out.
- **Probe files one by one**: Auto-level step 3 lists every file with a tick box. An unticked file is saved without correction. Unticking all of them switches probing off.
- **Tool library everywhere**: wrench button in the top bar, File → Tool Library / Export Tools / Import Tools. Your tools are kept across updates and can be saved to a `.tmtools` file.
- **Update check**: a banner tells you when a newer version is out (Help → Check for Updates…).
- **Recipe uses your own tools first** when you have one of the right type and size.

### Improved
- The app's own file browser everywhere: choosing files, a ZIP, opening a project, loading probe results, importing tools, and the save-folder button for a new project. No more Windows dialogs for opening files.
- Simulation runs about twice as fast (≈27 frames/s instead of ≈12).
- Mach3 / Mach4 probe grids start at 15 mm spacing.
- The height correction is taken relative to the point where each bit touched the copper.
- Cutout always runs outside the board outline. Tabs have their own switch, and their settings are kept when you turn them off.
- Every save shows a clear "✓ Saved … to <folder>" message, and the Export page remembers the last save.
- Projects record the version that saved them. A project saved by a newer version asks you to update.
- The auto-level step cards are the same height.
