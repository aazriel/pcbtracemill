Already on 0.1.1? Install 0.1.2 over it. Your settings, saved tools and .tmill projects carry over.

### First start
- **Windows:** the installer is not code-signed yet, so SmartScreen shows *"Windows protected your PC"*: click **More info -> Run anyway**.
- **macOS:** the app is not notarised yet. Right-click the app and choose **Open**. If macOS says it is damaged, run once in Terminal: `xattr -cr "/Applications/PCB TraceMill.app"`
- **Linux AppImage:** `chmod +x PCB-TraceMill-0.1.2-x86_64.AppImage` and run it. On Ubuntu 24.04+ you may need `--no-sandbox`.

## What is new in 0.1.2

### Auto-levelling
- **Board map on the Export page:** shows where each bit finds Z0 with the probe, as numbered dots in its file's colour. Point at a file to light up its points.
- **Your own Z0 point per bit:** press *Move* and click on the map, or type X/Y. *Auto* puts it back. If no copper there is still joined to the probe clip, the automatic point is used and yours is shown crossed out.
- **Probe files one by one:** tick the files to correct. An unticked file is saved as it is, and unticking all of them switches probing off.
- **Automatic Z0 point:** each bit touches off where copper is still left (isolation at the board centre, drilling on a hole it drills, cutout on its own line). The height correction is taken relative to that point.
- Mach3 / Mach4 probe grids start at 15 mm spacing.

### Tools
- **Tool library:** open it from the wrench button in the top bar or from File -> Tool Library. Export and import your tools as a `.tmtools` file.
- Your tools are kept across updates.
- The recipe uses your own tools first when you have one of the right type and size.

### Everything else
- **Own file browser:** the app's own browser is used for choosing files, a ZIP, opening a project, loading probe results and importing tools. It shows what is in each folder and remembers the last one.
- **Simulation:** about twice as fast (≈27 frames/s instead of ≈12).
- **Cutout:** always runs outside the board outline. Tabs have their own switch, and their settings are kept when tabs are off.
- **Saving:** every save shows a clear *"✓ Saved … to <folder>"* message.
- **Update check:** a banner tells you when a newer version is out (Help -> Check for Updates…).
- **Project versions:** projects record the version that saved them, and a project from a newer version asks you to update.

## Highlights
- Isolation (with smart clearance), copper clearing, drilling, hole milling, cutout with tabs
- Realistic 3D material-removal simulation
- Auto-levelling with probing (Mach3 heights kept in variables - no file to load)
